# Photo_Editor 1.4.2

## English

- Fixed the silent **Check for Updates…** command.
- Enabled the mandatory pre-extraction signature verification required by Sparkle for signed update feeds.
- Added a build check that prevents publishing an invalid updater configuration.

## Русский

- Исправлена неработавшая без сообщения команда **«Проверить обновления…»**.
- Включена обязательная предварительная проверка подписи, необходимая Sparkle для подписанной ленты обновлений.
- Добавлена сборочная проверка, исключающая публикацию неправильной конфигурации updater.
